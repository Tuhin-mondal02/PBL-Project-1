# PBL Project 1 – Spotify Song Popularity Prediction

## Project Overview
This project focuses on predicting the popularity of Spotify songs using Machine Learning techniques. It analyzes various audio features to understand the factors that influence song popularity.

## Objectives
- Analyze the Spotify songs dataset.
- Perform data cleaning and preprocessing.
- Identify factors affecting song popularity.
- Develop a Machine Learning prediction model.
- Evaluate model performance and visualize results.

## Technologies Used
- Python
- Google Colab
- Machine Learning
- GitHub
- Jupyter Notebook

## Dataset
The project uses a Spotify tracks dataset to study song characteristics and popularity.

## Project Workflow
1. Dataset Collection
2. Data Preprocessing
3. Exploratory Data Analysis
4. Feature Selection
5. Model Training
6. Model Evaluation
7. Prediction and Visualization

## How to Run
1. Download or clone this repository.
2. Open `spotify-song-popularity-prediction.ipynb` in Google Colab.
3. Upload the required dataset.
4. Run all notebook cells sequentially.
5. View the prediction results and visualizations.
